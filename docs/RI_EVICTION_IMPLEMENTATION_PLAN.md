## 5. Demo Script

### Pre-demo setup (2 min)
1. Open `/` in browser.
2. (Optional) Go to `/ri/materials` and confirm Handbook + Intake Form are pre-loaded (or upload if doing fresh).
3. Clear localStorage for clean run: DevTools → Application → Local Storage → delete `spb:ri-eviction:*` keys, or click "Reset" on intake.

### Demo flow (5–7 min)
1. **Landing** – "Helps Rhode Island tenants understand eviction-related issues" → **Start Intake**.
2. **Intake** – Either:
   - Click **Load sample** for instant populated case, or
   - Complete manually: name, phone, notice type (Pay or Quit), behind on rent, unsafe conditions, goals (Stay in home, Reduce rent debt).
3. **Review** – Confirm checkboxes → **See results**.
4. **Results** – Show:
   - Plain-language summary
   - Likely category (Nonpayment / rent arrears)
   - Issue flags (e.g., Unsafe conditions)
   - Immediate next steps
   - Documents to gather
   - **Grounding excerpts** (from Handbook/Intake Form)
5. **Case summary** – **View tenant case summary** → **Print / Save PDF**.
6. **Talking points**: "Tenant completes digital intake → gets structured guidance grounded in RI materials → generates case summary for legal staff. No generic chatbot; excerpts cited from Handbook and intake form."

### Fallback if issues
- If no citations: "Embedded materials are pre-loaded; you can also upload at /ri/materials."
- If sample data feels off: use Reset and fill minimal (name, phone, Pay or Quit, yes behind on rent) for a quick run.
